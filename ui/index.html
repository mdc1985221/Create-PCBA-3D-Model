导入生产资料，生成 3D / STEP、校准器件中心并进行基础 SMT DFM 检查。
01 / 导入资料

选择 Gerber、坐标和 BOM

先生成预览，再查位号、校准和检查坐标；确认后导出 STEP 或贴片坐标。

支持混拖文件与文件夹，自动查找 ZIP 内的坐标表。
    一次最多 100 MB，资料仅在本机处理。

    直接读取原生产资料中的 XLSX / XLS / CSV / TSV，以及 Allegro 的 place_txt.txt；无需改成模板。支持 REFDES、SYM_X/Y、SYM_ROTATE、SYM_MIRROR 表头和分开的 TOP/BOTTOM 工作表。ZIP 内的表格也能直接选择。

    检查 BOM / XY，手动排除重复行

    排除只影响本次生成，原文件不改动；排除后可恢复。BOM 整行排除会移除此行全部位号。

    XY 坐标行（也可排除重复位号）
    02 / 工程设置

    板框与输出

    从 Gerber 闭合轮廓和所选 XY 识别单板，自动对齐板层与器件，保留圆角；拼板中的文字、工艺边不计入单板。板厚请核对。
    每次生成独立工程文件夹，可直接输入本机绝对路径。

    缺模型或缺坐标的器件列入待处理清单。补齐后可生成完整 STP。

    默认先快速生成预览。之后可从预览的“器件 / 校准”面板重新导出 STEP。

    坐标、圆角与图层高级设置
    坐标以板框左下角为 (0,0)。Gerber 原点填源文件板框左下角坐标；XY 平移用于对齐坐标表。

    键：top_copper、bot_copper、top_mask、bot_mask、top_silk、bot_silk、top_paste、bot_paste、outline、drill。文件名填写 ZIP 内文件的文件名。

    优先识别 GKO、Edge.Cuts 和任意编号的 panel.art；缺少独立板框时，从 dill / dril / drill 钻孔图提取闭合板框。其他命名可指定，例如 {"outline":"板框.gbr"}；仍会校验轮廓闭合及与所选 XY 的对应关系。

    封装映射与可复用模型库

    左侧填写坐标表中的封装名，右侧填写模型库名称。新封装需在此匹配；保存后下次可复用。

    导入资料后显示封装匹配情况。
    

    

    

    

    点击模型名可复制；模型外观及适用封装请在 3D 中核对。
    

    

    手动导入模型 / 参数模型

    导入 STEP/STP 后先预览，确认方向、贴板原点和尺寸后保存到本机用户库。原生 STEP 同时用于装配导出，可重复使用。
    

    


    

    

    源模型按 Z 轴为高度，旋转顺序 X → Y → Z。插件引脚应低于贴板面，请使用自定义原点；几何最低点不一定是贴板面。可修改设置后重新预览。
    




    



    

    缺模型时：AI / 规格书 / API 设置
  
    普通生成完全离线。AI 生成和联网检索只发送下方输入的型号/尺寸说明，不发送整份 BOM、坐标或生产文件；“测试 API 连接”发送一条测试请求。调用可能产生 API 服务费用。
    



    




    

    

    密钥保存在 EXE 同目录的 API设置.json，请勿把此设置文件分享给他人。界面不会回显已存密钥。联网检索需 Tavily 搜索接口，或支持 web_search 的 Responses 服务。
    

    


    

    

    AI 参数模型用于近似包络，复杂结构推荐原厂 STEP；生成后需核对尺寸并手动保存入库。检索仅展示来源页面，下载文件后从上方导入。
    

    

    

    支持常用 Gerber、Excellon 钻孔、槽孔与闭合板框，请核对孔位、原点和器件方向。STP 包含实体、颜色及板面焊盘和丝印；Creo 导入请保留曲面与颜色。CAD 显示设置可能影响透明度和光照。
