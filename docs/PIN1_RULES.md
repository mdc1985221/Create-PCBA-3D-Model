# 第一脚与表面标记

v1.3.15：从制板 PAD 重建 BGA 时，先把原制板丝印转换到器件顶视坐标系，再找与本体相符的闭合轮廓和角部证据。支持圆点、圆圈、三角、轮廓倒角，以及孤立的单线字体 A、带旗部和底横的数字 1。A1 的两个字形均符合模板时可作为相邻标记。识别只覆盖保守的笔画模板，并非任意字体 OCR。

不会把电源名 VAA 中的 A、位号中的 1、单独一根竖线、缺球位置、普通矩形焊盘当成第一脚。缺少轮廓、清除极性图形、多个角的证据冲突或字形不明时保留待确认状态；用户应对照局部板面图和原厂规格书确认。自动识别不会改写生产坐标或任意旋转整颗器件。

封装家族本身不能确定板上的第一脚方向：

- BGA/CSP：以原厂 A1 说明与 PCB 第一球标记为准，缺球不等于 A1。
- QFN/DFN/WSON：以本体的第一脚标记区和原厂顶视/底视定义为准，圆点、斜角、底部焊盘倒角可能是不同视图。
- SOIC/TSSOP：以标记端、缺口及顶视编号为准，不能只看文字正向。
- SOT-23：不能假定每颗器件都有第一脚圆点，也不能把型号喷码里的点自动作为第一脚。同一外形的三极管、MOSFET、二极管与 IC 引脚功能可能不同，需核对具体料号。
- 二极管、LED、电解电容：极性条/缺口/加减号是极性信息，不能直接等同 IC 第一脚。

本轮查阅的原厂资料：

- [onsemi MMBT3904LT1G](https://www.onsemi.com/pdf/datasheet/mmbt3904lt1-d.pdf)：SOT-23 引脚功能、封装与 marking diagram，应按具体料号解读。其首页明确写明“Microdot may be in either location”，因此不能把喷码小圆点位置一律当成第一脚。
- [TI TPS62130](https://www.ti.com/lit/ds/symlink/tps62130.pdf)：RGT0016C VQFN 封装图标注 PIN 1 INDEX AREA / PIN 1 ID。
- [TI TPS62160](https://www.ti.com/lit/ds/symlink/tps62160.pdf)：DGK0008A VSSOP 及 DSG0008A WSON 的标记区、顶/底视编号。

这些资料用于核实规则边界，不表示已对库中所有模型逐一按原厂校验。当前自动字形识别接入的是制板 PAD 重建 BGA 流程；其他模型的物理原点与第一脚方向仍需按规格书及实际封装校准。

表面字样来自 BOM 时只是识别文字，并非原厂批次激光码。照片重绘也应注明难辨字符与 Logo 描绘误差。真实实体凹刻会进入新导出的 STEP；仅网页纹理无法替代实体刻字，旧 STEP 文件不会自动更新。
