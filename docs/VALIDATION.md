# 公开整理版验证

公开版基于本地 v1.3.1 的功能代码。为了公开分发，资源中只包含 64 种来源和许可可追溯的常规模型，不包含原生产工程、API 设置、真实板样例或未明确再分发许可的厂商模型。

运行 `python scripts/verify_public.py` 会检查：

1. 64 种模型、封装映射及所有原生 STEP 路径完整。
2. 公开目录不存在 API 设置、生产输入或 EXE；实际密钥格式扫描不通过时直接失败。
3. 合成的 40 × 30 mm 板、6 个器件（4 顶 / 2 底）可生成完整预览。
4. 输出 STEP 已回读验证，导出的 SMT 本体中心和输入坐标一致。
5. 本地服务和原生 CAD 依赖另由 `python src/app.py --self-test` 验证。

该测试验证公开包的安装与生成链路，不代表各种 EDA 输出、所有封装或设备程序均已覆盖。运行报告在 `_work/public-verification.json`，不写入源资料。

原本地模型补库阶段曾验证 37 种电感/二极管的 296 个顶底面及旋转组合，并在原生产资料上回归 242 个实装器件。原始测试工程与生产资料继续保留在本地，不随公开仓库上传；公开 CI 使用完全合成资料重现基本流程。
