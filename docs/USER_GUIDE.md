# PCBA3D 操作说明

## 1. 准备资料

需要 XY（位号、X、Y、旋转、面别、封装）、BOM 及 Gerber/Excellon。XY 与 Gerber 应共用已知原点；若不同，使用 XY 平移进行对齐。XLSX/XLS、CSV/TSV 及 Allegro 原始 placement TXT 可直接尝试读取，识别结果仍须人工核对。

导入支持多文件、目录、ZIP；列表可移除文件。展开资料核对表可排除/恢复重复行，原文件不改写。ZIP 中有同名冲突时，可先解压并按需选择。检查文件路径、坐标单位和 BOM 版本，避免混入不同版号的坐标。

本公开包不附真实生产板样例。初次使用可导入 `examples/synthetic` 的合成输入；铜、阻焊只是示意标记，不是实际焊盘设计。

## 2. 板框、板厚与原点

优先从闭合 panel/profile/GKO/Edge.Cuts 等外框提取单板范围，并与 XY 核对；Allegro 的 dill/dril/drill 钻孔图中存在闭合板框时可作为候选。钻孔符号和图例不能替代 NC 孔位。

板框不唯一或未识别时，在图层文件名 JSON 指定 `{"outline":"实际板框文件.gbr"}`。规则矩形/圆角矩形可关闭自动识别，输入宽、高、圆角和原点；异形板需要真实轮廓。不能用铜皮最大范围代替板框。

**板厚手动填写**，例如 1.0、1.2、1.6、2.0 mm；自动识别板框不等于知道板厚。XY 平移与 Gerber 原点必须按同一基准核对。

## 3. 模型匹配

封装名通过 `assets/aliases.json`（基础）和程序旁边的 `aliases.json`（用户）映射到模型编号。展开“封装映射与可复用模型库”查看已匹配、待匹配和映射模板。保存用户映射后下次可复用。

缺模型时可先生成已匹配部分，待处理项明确列出。不能把缺失器件当作已经完成，也不会凭空生成未知坐标。完整 STEP 需要先处理缺项。

导入 STEP/STP 时，先核对单位、原点、方向和尺寸。默认几何 XY 中心及最低点适合很多贴片器件；非对称连接器或带插板针的模型通常需要自定义原点。当前单文件导入上限 30 MB。预览确认后绑定生产坐标表中的封装名，保存到用户模型库。重复名称不会覆盖既有模型。

移动程序时带上用户模型库和映射文件。旧工程有自己的模型快照；补库后重新生成，才会使用新模型。

## 4. 预览与手工贴片找料

- 输入完整位号并定位，自动翻到所在面、高亮和放大；“全板”恢复范围。
- BOM 搜索支持数值、型号、封装和位号；`µF`、`μF`、`uF` 按等价形式处理。
- 点击 BOM 行，高亮该物料当前面全部器件；切换顶/底面继续摆料。
- 点击 PCB 器件，自动定位并高亮对应 BOM 行；筛选隐藏时会清除筛选使其可见。
- “器件 / 校准”可展开或收起，不会因此保存或清空未保存的修改。
- 顶/底/等轴 PNG 可用于辅助装配。贴装数量只是备料数量辅助，不是加工费估算。

## 5. 校准

从 1.3.6 起，校准面板停靠在画布旁，占用独立区域，不覆盖电路板。宽窗口可同时显示 BOM、3D 和校准；宽度不超过 1050 像素时，校准替换左侧 BOM 工具，3D 区继续可操作。点击校准面板顶部“BOM / 视图 ×”返回左栏，再从“器件 / 校准”重新打开。选择、输入值和未保存调整在开关面板时保留。

左侧 BOM / 视图栏与校准栏各自可滚动；把鼠标放在对应栏里滚轮向下，即可访问底部内容。也可聚焦该栏后用键盘翻页。窗口大小或面板开关改变时，画布自动同步尺寸，保持当前查看目标。

X/Y 按板顶视坐标输入。平移按钮支持可调粗调、微调和长按；面板内 Alt+方向键使用当前步长，Alt+Shift+方向键使用粗调。旋转支持顺/逆 90°、180°及自定义步长；按钮方向按器件所在面转换，数字旋转修正仍按板顶看逆时针为正。

“点选引脚 → 焊盘”先选金属引脚，再选当前面的焊膏焊盘或阻焊开窗，吸附到中心，只调整 X/Y。可选择点击点、引脚几何中心或模型原点作为起点。复杂连通金属需要特别核对；该功能不理解电气引脚编号或极性。

完成后点击“保存本器件”。“保存为封装规则”还会保存封装+模型校准，按方向和面别转换后供后续生成复用；不会立即移动当前工程其他器件。“撤销未保存”回到最近保存状态，“清零”需要再次保存才生效。

## 6. 修正坐标与基础 DFM

先保存全部调整，再导出。默认本体包围盒中心，去掉引脚和标记；没有本体/端子分类的模型会提示复核，可在明确基准后选择模型原点。安装类型可选 SMT、THT、排除或自动识别。

导出可选源资料原点 / 单板原点，角度可选板顶视 / 器件所在面视角。底面 XY 不自动镜像，角度不做特定设备的封装零度转换。SMT 输出到贴片清单，THT 保留核对。缺模型/坐标/中心确认项时默认阻止完整导出；部分导出会明确标记。

DFM 检查同面本体包围盒重叠、板框越界、与原坐标的中心偏移及待处理项。它不检查完整焊盘、极性、电气、吸嘴或工艺规则。**本体中心不一定是吸取点，导出表不能免去贴片机程序核对。** 原 BOM、XY、Gerber 不会被回写覆盖。

## 7. STEP

预览先生成，STEP 可后台计算或校准后重新导出。实体多、孔多或板层复杂时可能耗时数分钟。成功回读检查后才提供完整下载；失败时保留预览和报告。

单位为 mm，器件颜色和装配关系尽量保留。板层外观是带色 BREP 薄面，CAD 导入需开启曲面和颜色；透明、光照、图片印字及网格细节可能与网页不同。重新导出前需保存校准，历史导出文件留在工程内。

## 8. 可选 AI / API

不配置也能离线完成常规工作。使用时自行填写接口、准确模型名及密钥，先测试连接。支持的接口和检索方式以界面为准。选择 PDF 和尺寸图页码时先在本地提取文字；扫描版不能保证可读，草稿只能表达简单 box/cylinder 几何。

仅点击 API 测试、AI 生成或搜索才会发送当前说明/检索词；正常生成不自动上传 BOM/XY/Gerber。不自动执行 AI 代码或安装网上模型。复杂机械外形请优先导入有权使用的原厂 STEP。

`API设置.json` 是本机明文设置，包含凭据时必须单独保护；不要上传 Git、发给他人或连同程序包公开分发。公开包不提供账号、密钥或额度。

## 9. BOM 识别与数据检查（1.3.2）

BOM 按位号等表头识别，文件名不需要包含 `BOM`。导入后会优先选择按内容识别出的独立 BOM，XY 表不会仅因为位于名为 BOM 的文件夹中就被自动当成 BOM。

同一行重复填写位号时，只列出真正重复的位号，并显示行号、用量、位号条目数和不同位号数；跨行重复时也会显示原行号。导入核对区会自动展开异常，提前显示用量与不同位号数不符的问题。请核对原表后重选文件，工具不会自动删减或猜测缺失位号。排除整行会同时排除这一行所有器件。

从 1.3.3 开始，Excel 提示明确标明 Excel 左侧行号、BOM 表内的序号（存在该列时）和位号单元格地址。例如“Excel 第 46 行（BOM 序号 44；位号单元格 F46）”表示去 Excel 的 F46 单元格检查，而不是查找序号为 46 的物料。CSV 没有 Excel 单元格时只显示文件行号和已有的 BOM 序号。

## 10. 预览加载与重复内孔（1.3.4）

有些资料在板框图层和 ROU 中重复描述同一个内孔，轮廓方向或采样点数可能不同。生成时会按双向边界距离合并误差不超过 0.001 mm 的重复轮廓，并在导入检查中报告数量；不同形状或不同位置的槽孔保留。

板体网格在本地后台线程计算，板芯与两面阻焊复用计算结果。正常加载会依次显示载入数据、后台计算板体、放置器件。若复杂或相交轮廓导致网格计算超过 30 秒，会终止后台计算并显示错误，页面仍可关闭或重试。需要通过 EXE 的本地服务打开预览，以加载模块和后台脚本；请保留工程的 vendor 文件夹。

## 11. 封装与 3D 模型绑定（1.3.5）

导入 BOM/XY 后，在“封装映射与可复用模型库”查看完整封装名、器件位号和物料说明。点击该行“选模型”，按名称、已有适用封装或来源文件搜索。点击候选模型查看 3D、长宽高、顶视引脚分布和侧视高度；确认外形尺寸、引脚数、节距与引脚 1 后点击绑定。模型名字相似不代表可以互换。同一个封装组中的物料描述若有冲突，应先核对原 BOM。

勾选“同时记住此封装”会保存为本机可复用映射；取消勾选只修改当前工程设置。单项绑定只更新当前目标，保留其他未保存的映射。修改后需重新生成 PCBA，已有历史工程不会自动改变。

没有合适模型时，从封装行点击“导入 STEP”，或在选择窗口点击“导入新的 STEP”。目标封装会自动带入完整名称，不要用通用的 `bga` 替代具体封装。选择 STEP 后自动生成英文模型名，已有同名模型会自动避让；手动改名若重名则提示错误，避免覆盖旧模型。也可选择“只保存到模型库”，稍后再绑定。

先预览，黄色点表示模型放置原点，网格为贴板面，红 X / 绿 Y / 蓝 Z。几何中心不一定是封装放置基准，插件引脚最低点也不等于贴板面；应根据规格书设置旋转和自定义原点，再预览确认。修改文件、名称、旋转、原点、材质或参数 JSON 后，原预览失效，必须重新预览后保存。模型预览成功后才允许确认入库。

独立模型预览用于外形与基准核对，不会自动识别电气引脚或与 Gerber 焊盘一一对应。整板生成后再使用器件校准、旋转与引脚吸附检查实际对齐。缺少匹配模型的封装可以保持待匹配，先生成其余部分预览。
